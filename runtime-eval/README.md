## Current Artifact Expectations
- Per match:
  - `metadata.json`
  - `scorecard.json`
  - `arena_result_match_a.json`
  - `build.log`
  - `test.log`
  - `stderr.log`
  - `trajectory_summary.json`
  - `trajectory_compact_match_a.jsonl`
  - `trajectory_events.json`
  - `agent_feedback_<agent_id>.json`
  - `agent_feedback_<agent_id>.md`
- Per run:
  - `logs/initial_synthesis_manifest.json`
  - `logs/round_1/initial_propagation_manifest.json`
  - `logs/round_<r>/round_manifest.json`
  - `logs/round_<r>/revision_manifest.json` for revision rounds
  - `logs/round_<r>/propagation_manifest.json` after revision propagation
  - `logs/tournament_report.json`
  - `logs/tournament_report.md`
- `arena_result_match_b.json` and `trajectory_compact_match_b.jsonl` are not required and should not be emitted by current single-leg formal runs.

## Feedback Inputs Per Round
- Feedback Package v4 is a factual package over schedule metadata, scorecards, official record JSON when available, compact trajectory actions, and public runtime logs.
- Compact trajectory v2 is lightweight per-step process feedback, not full replay.
- Death causes, bomb ownership, power-up pickup causes, full board arrays, and full observations remain future work unless a later feedback package explicitly adds them.

## Revision Autonomy
- Runner/config controls revision invocation via `revision_rounds`, `revision_subset_size`, and `require_all_agents_revised`.
- During OpenClaw revision, the model autonomously decides how to modify code.
- Route provenance is required for accepted synthesis/revision:
  - `provider_route_status=matched`
  - non-empty `actual_provider` and `actual_model`
  - `fallback_used=false`
- If route provenance is unknown, the result is treated as unverified and retried from clean base when configured.

## Generated Artifacts Policy
- `workspace/` is generated runtime state.
- `logs/round_*` are generated run artifacts.
- Generated artifacts should not be versioned.
- Verify with:
  - `git ls-files workspace`
  - `git ls-files logs`
